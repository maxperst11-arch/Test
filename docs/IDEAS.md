# Идеи на потом

Сюда складываем то, что не входит в первую версию.

## Регулярные задачи

Задачи, которые повторяются по расписанию: «отчёт каждый понедельник», «оплатить интернет 10-го числа», «отбой в 23:00 каждый день».

- Шаблон повторения: ежедневно, по дням недели, раз в месяц, каждые N дней.
- После «✅ Сделал» бот сам создаёт следующий экземпляр с новым дедлайном.
- В «Дневнике позора» отдельная серия по каждой регулярной задаче.
