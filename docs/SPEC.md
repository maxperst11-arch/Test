# Волшебный сапог — спецификация

Telegram-бот, который принимает задачи, спрашивает дедлайн и напоминает о них. Чем ближе дедлайн, тем чаще напоминания. Тон — строгий учитель, который снова поймал тебя без домашки: грубо, но без мата.

## Пользователи

- Сначала бот работает для одного владельца, но архитектура многопользовательская с первого дня: у каждого свои задачи, темы и настройки.
- Доступ ограничивается переменной `ALLOWED_USERS`: Telegram ID или @username через запятую. Пустое значение означает, что бот открыт для всех; так можно будет поделиться им с друзьями.

## Главное меню (`/start`)

Приветствие-наезд, затем кнопки:

| Кнопка | Что делает |
|---|---|
| 📋 Мои задачи | Все активные задачи по срочности, фильтр по темам |
| 🔥 Горит | Просроченные и задачи с дедлайном сегодня |
| ➕ Новая задача | Пошаговое добавление |
| 🗂 Темы | Разделы и темы: просмотр, добавление, переименование, удаление |
| 📊 Дневник позора | Сделано / просрочено / перенесено, серия дней без просрочек |
| ⚙️ Настройки | Тихие часы, часовой пояс, время утренней сводки, уровень злости |
| ❓ Справка | Как пользоваться |

## Темы

- Два уровня: **раздел → тема** (например, «Личное → Финансы»).
- Стандартный набор при первом запуске:
  - Личное: Финансы, Режим сна, Полезные привычки
  - Работа: Отчётность, Регулярные обязанности
  - Учёба
  - Здоровье
- Всё можно переименовать, удалить и дополнить. При удалении темы с задачами бот спрашивает, куда их перенести.

## Важность и срочность

- **Важность** задаётся вручную: 🔴 Важно / 🟡 Средне / ⚪ Мелочь.
- **Срочность** вычисляется автоматически из времени до дедлайна.
- Порядок в списке: просроченные → по времени до дедлайна; при равной срочности важные выше.

## Добавление задачи

1. Текст задачи. Если отправить боту текст вне меню, он предложит сделать из него задачу.
2. Тема: кнопки с темами и «➕ Новая тема».
3. Важность: три кнопки.
4. Дедлайн: «Сегодня», «Завтра», «Через 3 дня», «Через неделю», «Своя дата». Своя дата пишется текстом: `25.10 18:00`, `через 2 дня`, `в пятницу`. Если время не указано, по умолчанию 20:00.
5. Карточка для подтверждения → ✅ Сохранить.

## Напоминания

Базовый интервал зависит от времени до дедлайна:

| До дедлайна | Интервал |
|---|---|
| > 7 дней | только утренняя сводка |
| 3–7 дней | 12 ч |
| 1–3 дня | 4 ч |
| 6–24 ч | 2 ч |
| 2–6 ч | 1 ч |
| < 2 ч | 30 мин |
| просрочено | 1 ч, текст с каждым разом грубее |

- Множитель важности: 🔴 ×0.75, 🟡 ×1, ⚪ ×1.5.
- Уровень злости в настройках (строгий / очень строгий / беспощадный) масштабирует интервалы: ×1.25 / ×1 / ×0.75.
- **Тихие часы** по умолчанию 23:00–08:00. Ночью бот молчит; напоминание, выпавшее на ночь, переносится на утро и попадает в утреннюю сводку.
- Кнопки под напоминанием: ✅ Сделал / ⏰ Отложить (1 ч, 3 ч, до завтра) / 📅 Перенести дедлайн / 🗑 Удалить.
- После трёх откладываний подряд бот язвит. Каждый перенос дедлайна попадает в «Дневник позора».

## Утренняя сводка (08:00)

- Каждый день в 08:00 по часовому поясу пользователя (время настраивается) бот сам пишет «доброе утро» в своём стиле и присылает план на день:
  - 🔥 просроченные;
  - задачи с дедлайном сегодня;
  - ближайшие дедлайны на следующие дни (до 5 штук).
- Если задач нет, бот всё равно здоровается и язвит, что подозрительно пусто.

## Настройки

- Тихие часы (начало/конец).
- Часовой пояс (по умолчанию Europe/Moscow).
- Время утренней сводки (по умолчанию 08:00).
- Уровень злости.
- Вечерняя сводка «что сделано за день» (вкл/выкл, по умолчанию выкл).

## Тексты

Все фразы лежат в `magic_boot/texts.py`, по несколько вариантов на ситуацию, бот выбирает случайный.

## Технологии

Python 3.12+, aiogram 3, SQLite (aiosqlite), Docker. Напоминания и сводки отправляет фоновый цикл, который просыпается каждые 30 секунд.
